AI and tech

Memory chips hit by a Chinese design claim. CXMT, China's largest DRAM maker, said it will ship a server memory module using a denser "4F²" cell by year-end. Micron fell about 3% to 4%, SK Hynix about 3.7% and Samsung about 4% (IBTimes). DRAM is the working memory that AI servers feed chips from, so cheaper Chinese supply threatens the pricing behind Micron's rally.

Meta's Muse Wonder. Meta released its first frontier-class model, claiming it matches ChatGPT and Claude on coding and legal or financial questions; no benchmark scores were published (Quartz).

Microsoft Maia 300. Microsoft unveiled an in-house inference chip (inference means running a trained model, not training it), claiming 40% more output per megawatt than leading GPU systems, with deployments from 2027 (Yahoo Finance). It is another hyperscaler step away from Nvidia.

Explained

Where this goes: why a smaller memory cell moved chip stocks.

Try first: If every parking space on a lot got a third smaller, how many more cars would fit?

The idea: A memory chip is a grid of tiny cells, each storing one bit. Shrink each cell and the same chip holds more data, so each gigabyte costs less. Today's standard cell takes up 6 units of area; CXMT says its new cell takes 4. That is about 33% less area per bit, like repainting a car park with smaller bays. Engineers call this the "4F²" layout, where F is the smallest line a factory can draw. Making it work needs a transistor that stands upright instead of lying flat, which is hard to build.

Still unknown: CXMT has given no yields or volumes, and SK Hynix and Samsung have their own 4F² roadmaps.
